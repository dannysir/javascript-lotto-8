## 🧐  목표 계획서.

### 요구 사항.

**입력**
- 입력은 총 3회 받는다.
  1. 구매 금액.
  2. 당첨 번호.
  3. 보너스 번호.

**로또 진행**
- 당첨은 1등 ~ 5등까지 존재.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 입력한 금액 만큼의 로또를 발행.
- 로또 1장의 가격은 1,000원.

**출력**
- 구매한 로또와 당첨 번호를 비교하여 결과 및 수익률 출력.
- 수익률은 소숫점 둘째 자리에서 반올림 (ex. 100.0%)

**예외 처리**
- 구입 금액.
  - 숫자만 입력.
  - 1_000 단위로만 입력.
- 당첨 번호.
  - `,` 쉼표로 구분.
  - 1~45 사이의 중복되지 않는 숫자 6개.
- 보너스 번호.
  - 숫자만 입력.
  - 앞선 당첨 번호와 중복되지 않는 1~45사이의 숫자.
